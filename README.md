# Nutrition E-Commerce (đồ án AWS)

Nền tảng thương mại điện tử thực phẩm có AI tra cứu dinh dưỡng, chạy trên AWS (ap-southeast-1).

- Quy tắc làm việc với Codex: `AGENTS.md` (gốc), `frontend/AGENTS.md`, `backend/AGENTS.md`
- Cấu hình quyền cho Codex: thư mục `.codex/` (đọc `.codex/README.md` trước khi dùng)
- Kiến trúc, quyết định, schema, API, test: thư mục `docs/`
- Hướng dẫn thiết kế giao diện: `docs/ui-guidelines.md`; ảnh tham chiếu: `docs/design-refs/`
- Mẫu prompt giao việc cho Codex: `docs/prompts.md`
- Kế hoạch từng giai đoạn, tiêu chí nghiệm thu, prompt mẫu: `docs/playbook.md`
- Tiến độ hiện tại: `docs/PROGRESS.md`

Các thư mục `infra/`, `.github/workflows/` đang rỗng (chỉ có `.gitkeep`). `backend/` và `frontend/` chỉ có `AGENTS.md`. Codex sẽ tạo nội dung theo kế hoạch trong `docs/playbook.md`.
