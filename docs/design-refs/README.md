# Ảnh tham chiếu thiết kế

Đặt vào đây các ảnh Codex nên bám theo (PNG / JPG, rộng tối đa ~2000px).

Quy ước tên file: `<màn-hình>-<mobile|desktop>.png`, ví dụ `product-list-desktop.png`, `product-detail-mobile.png`, `chat-desktop.png`.

Gợi ý nguồn:
- Wireframe vẽ tay hoặc Figma (export PNG).
- Screenshot các trang bạn thích (ghi chú bạn thích điểm nào: bố cục, màu, bảng dinh dưỡng...).
- Ảnh chụp từ `npm run screenshots` của bản trước, kèm ghi chú muốn sửa gì.

Khi giao việc, ghi rõ: "Bám bố cục theo `docs/design-refs/<file>`, màu và font theo `docs/ui-guidelines.md`". Ảnh chỉ để tham chiếu bố cục và cảm giác; tokens trong `ui-guidelines.md` vẫn là nguồn chuẩn.
